## Logos

- `public/brand/meluma-logo-light.svg` e `.png`: versão clara, transparente, para fundos escuros.
- `public/brand/meluma-logo-dark.svg` e `.png`: versão escura, transparente, para fundos claros.
- `public/brand/meluma-mark.svg` e `.png`: símbolo compacto para favicon e usos pequenos.

## Paleta

- Ameixa escura: `#19131A`
- Papel quente: `#F2E8D8`
- Terracota: `#C8795B`
- Latão: `#C8A96A`

Tipografia usa fontes locais do sistema: Georgia para títulos e Arial/Helvetica para leitura. Nenhuma fonte externa é carregada.
